One line of real-life patch notes — a software changelog entry for a bug in daily life. The program writes that line to `/output/entry.txt`:

> v1.3.9: fixed a bug where walking into a room deleted the reason you walked in there.

## Why this line

It is unmistakably a patch note about a real-life bug: a version number, the "fixed a bug where" register, and a fix stated as if it shipped. The joke lands on a first read and rests on a real comedic idea, not just the word bug dropped into a sentence — the verb "deleted" is the joke: a doorway acting like a careless piece of software wiping your short-term memory. It names a specific, recognisable bug of daily life that everyone has hit: walking into a room and blanking on why you went in, so the reader winces and laughs at once. At 85 characters it uses its space well: no padding, no setup the punchline does not need, every word working.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
